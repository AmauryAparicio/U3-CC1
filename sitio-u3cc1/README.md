# Café Nahual – Actividad Complementaria 1 (U3-CC1)

Sitio WordPress de una empresa ficticia (tostaduría de café), con tema propio, plugin de contacto propio y paquete de migración a InfinityFree.
Materia: Desarrollo de Sitios Web con Transacciones en Línea, SUAyED FCA UNAM. Autor: Jorge Amaury Aparicio Cuevas (grupo 8691).

| Carpeta | Contenido |
|---|---|
| `wp/wp-content/themes/cafe-nahual` | Tema propio (`style.css` externo) |
| `wp/wp-content/plugins/nahual-contacto` | Formulario `[formulario_contacto]` → tabla `wp_contactos` |
| `scripts/` | Contenido de páginas, instalación, capturas (Playwright), empaquetado, FTP y PDF |
| `evidencias/` | Capturas numeradas |
| `migracion/` | SQL con URLs reemplazadas, `wp-content.zip`, guías (InfinityFree y XAMPP) |
| `documento/` | Documento de evidencias en PDF |
| `NOTAS.md` | Credenciales **locales** de prueba |
